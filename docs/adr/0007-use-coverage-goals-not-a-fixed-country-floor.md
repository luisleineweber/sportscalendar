# Use coverage goals instead of a fixed country floor

**Status:** Accepted

Do not impose a fixed per-country list or count of sports and events as a `Ready` gate. Aim to include football, basketball, athletics, and other national competitions in each target country. The coverage report shows these goals by country and sport and reports gaps, but treats them as goals; only separately named required highlights block `Ready`. This supports broad coverage without forcing a fixed inventory before reliable events are found.
